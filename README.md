
# Library Database

A library management database built with **SQL Server** and **T-SQL**.

## Tables
- **Members**: library members
- **Books**: the book catalogue
- **Loans**: which member borrowed which book, and when

## How to run
1. Install SQL Server and SSMS.
2. Create a database called `ProjDB`.
3. Run the scripts in numbered order.
